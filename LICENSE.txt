1. 적용 범위와 권리
이 약관은 제작자가 배포하는 Windows용 SnapBerry 실행 프로그램(EXE), 함께 제공하는 문서 및 제작자가 GitHub 공개 저장소에 게시한 소스 코드·문서·자산 중 제작자에게 권리가 있는 부분에 적용됩니다. 외부 구성 요소에는 제7항의 각 라이선스가 우선 적용됩니다. 이용 전에 이 약관을 확인해 주세요. 동의하지 않는 경우 프로그램을 사용하지 말고 삭제해 주세요.
SnapBerry는 무료 소프트웨어입니다. 무료 배포나 소스 코드의 공개가 저작권의 포기 또는 오픈소스 라이선스 부여를 의미하지 않습니다. 프로그램과 제작자 소유 자산의 권리는 제작자에게 있으며, 이 약관에서 명시적으로 허용하지 않은 권리는 유보합니다.

1-1. GitHub 공개 저장소의 열람과 포크
제작자가 GitHub 저장소를 공개한 경우, 다른 이용자가 GitHub 서비스 기능과 서비스 약관이 허용하는 범위에서 해당 저장소를 열람·표시·이용하거나 포크하여 GitHub 내 자신의 저장소에 사본을 만드는 것을 인정합니다. 이 약관은 GitHub와 그 이용자에게 GitHub 서비스 약관에 따라 부여되는 권리를 제한하지 않습니다.
공개 저장소의 열람·포크는 그 자체로 오픈소스 라이선스를 부여하거나, GitHub 서비스 약관이 허용하는 범위를 넘어 소스 코드·프로그램을 수정하고 파생 프로그램을 제작하거나 수정본을 배포할 권한을 부여하지 않습니다. 이러한 행위에는 법령 또는 외부 구성 요소의 라이선스에 따라 허용되는 경우를 제외하고 제작자의 사전 허락이 필요합니다. 프로그램의 판매·대여·유료 재배포 등에는 제3항의 제한이 계속 적용됩니다.

2. 무료 사용 허가
개인 및 기업, 기관, 교육기관은 개인·업무·교육·영리 활동을 포함한 적법한 목적으로 이 버전의 SnapBerry를 무료로 설치하고 사용할 수 있습니다. 사용을 위한 실행 파일 복제 및 백업을 허용합니다. 이 허가는 비독점적이며 프로그램의 소유권을 이전하지 않습니다.
이용자가 캡처·편집·내보내기한 이미지에 대해 제작자가 별도의 권리를 주장하지 않습니다. 결과물은 이용자와 원본 콘텐츠 권리자의 권리에 따라 사용할 수 있으며, 결과물 사용 시 SnapBerry 출처 표시를 요구하지 않습니다.

3. 무료 재배포
제작자가 배포한 원본 실행 파일을 변경하지 않고 무료로 공유할 수 있습니다. 이 약관, 데이터 처리 안내 및 포함된 외부 구성 요소의 고지를 유지하고 수신자가 확인할 수 있도록 해야 합니다. EXE에 내장된 고지를 제거해서는 안 됩니다. 제작자의 공식 배포처나 후원을 받는 제품으로 오인하게 표시해서는 안 됩니다.
프로그램 자체의 판매·대여·유료 이용권 제공, 유료 상품에 포함한 재배포, 광고·다른 프로그램을 추가한 재포장 또는 변조본 배포에는 제작자의 사전 허락이 필요합니다. SnapBerry를 업무에 사용하거나 결과물을 영리 목적으로 사용하는 것은 이 제한에 해당하지 않습니다.

4. 제한과 이용자 책임
법령, 제1-1항 또는 외부 구성 요소의 라이선스에 따라 허용되는 경우나 제작자의 사전 허락이 있는 경우를 제외하고, 소스 코드·프로그램의 수정, 파생 프로그램 제작·수정본 배포, 소스 코드 추출을 위한 역분석·디컴파일·역어셈블, 보호 조치 우회 또는 저작권 표시 제거를 허용하지 않습니다.
다른 사람의 저작권·개인정보·영업비밀 등을 침해하거나 불법 감시 등 위법한 목적으로 사용해서는 안 됩니다. 캡처 권한 확인과 결과물의 적법한 이용·공유는 이용자의 책임입니다.
법령에 따라 보장되는 이용자의 권리와 외부 구성 요소의 라이선스가 부여하는 권리는 이 약관으로 제한하지 않습니다.

5. 데이터와 안전한 사용
데이터 처리 방식은 함께 제공되는 'SnapBerry 데이터 처리 안내'에 설명합니다. 내부 캡처 이력에는 모자이크·자르기 전 원본 이미지가 남습니다. 외부 공유에는 PNG 내보내기를 사용하고, 내보낸 이미지에 민감한 정보가 남아 있지 않은지 직접 확인해 주세요. 모자이크는 모든 정보의 복원 방지를 보장하는 기능이 아닙니다.
중요한 데이터는 별도로 백업해 주세요. 이력 삭제에는 복원 기능이 없으며 프로그램 종료·업데이트·삭제 전에는 필요한 결과물을 저장해 주세요.

6. 보증과 책임 범위
프로그램은 현재 제공되는 상태로 배포됩니다. 법령이 허용하는 범위에서 특정 목적 적합성, 모든 환경에서의 정상 작동, 오류 없는 동작 또는 지속적인 업데이트·기술 지원을 보증하지 않습니다.
법령이 허용하는 범위에서 제작자는 프로그램 이용으로 발생한 손해에 대한 책임을 제한합니다. 다만 제작자의 고의 또는 중대한 과실로 발생한 손해, 관계 법령상 배제하거나 제한할 수 없는 책임과 이용자의 법정 권리에는 이 제한을 적용하지 않습니다.

7. 외부 구성 요소
포함된 외부 라이브러리·런타임 등의 권리는 각 권리자에게 있으며 해당 라이선스가 우선 적용됩니다. 관련 안내는 THIRD-PARTY-NOTICES.md를 참고해 주세요. 이 약관은 외부 구성 요소를 제작자의 독점 저작물로 변경하거나 각 라이선스의 권리를 축소하지 않습니다.

8. 이용 종료와 변경
이용자는 언제든 프로그램 사용을 중단하고 삭제할 수 있습니다. 프로그램을 삭제해도 사용자 데이터가 자동 삭제되지는 않으며, 삭제 방법은 데이터 처리 안내를 참고해 주세요. 이 약관을 위반한 사용은 허가 범위에 포함되지 않습니다.
새 버전에 다른 조건을 적용하는 경우 해당 버전과 함께 변경 내용을 안내합니다. 새 조건을 이미 배포된 이 버전의 적법한 사용에 소급 적용하지 않습니다. 일부 조항이 무효이더라도 나머지 조항은 법령이 허용하는 범위에서 유지됩니다. 이 약관은 대한민국 법률에 따르며 강행 법규에 따른 이용자의 권리를 제한하지 않습니다.
