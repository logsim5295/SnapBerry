SnapBerry 설치 안내

1. SnapBerry 아이콘을 옆의 Applications(응용 프로그램) 폴더로 끌어 놓으세요.
2. Finder의 응용 프로그램 폴더에서 SnapBerry를 더블클릭하세요.
3. 설치 디스크는 추출해도 됩니다.

터미널 명령이나 별도 .NET 설치는 필요하지 않습니다. macOS 14 이상을 지원합니다.

이 파일은 Developer ID 서명·Apple 공증 전 시험 버전입니다.
처음 열 때 개발자를 확인할 수 없다는 이유로 차단되면, 신뢰하는 이 배포 파일인지 확인한 뒤
시스템 설정 → 개인정보 보호 및 보안에서 SnapBerry의 '그래도 열기'를 선택하세요.
https://support.apple.com/ko-kr/102445
