# macOS 기능 동등성 구현 계획

**목표:** 앞서 확인한 맥 미구현 기능을 기존 앱에 추가하고 Windows와 편집·이력 동작을 맞춘다.
**설계:** `docs/superpowers/specs/2026-10-22-macos-parity-design.md`
**구조:** 기존 MainWindow를 역할별 partial로 나누고, OS 경계는 독립 서비스로 둔다. 독립 파일을 담당하는 병렬 작업 후 메인 UI를 통합한다.
**제약:** GUI/실제 캡처/로그인 설정은 로컬에서 실행하지 않는다. 기존 packages.lock.json 변경을 보존한다. 정상 Release 빌드와 Portable EXE를 갱신하며 EXE는 LFS로 커밋한다. 사용자 요청 없이 푸시하지 않는다.

## 1. 플랫폼 서비스
- [x] 다중 모니터 캡처의 좌표·배율·합성·실패 정리 테스트를 먼저 추가한다.
- [x] MacCaptureService와 독립 다중 화면 합성/열거 경계를 구현한다.
- [x] 사용자별 LaunchAgent 등록/해제 서비스를 가짜 실행 경계와 임시 디렉터리로 검증한다. 실제 로그인 설정은 실행하지 않는다.

## 2. 설정 및 정보 창
- [x] 키 직접 입력·Esc 복원·기본값 복원과 저장 오류 테스트를 추가한다.
- [x] 독립 색상 선택/이미지 크기/텍스트/정보 창을 구현한다. 메인 창과의 연결은 주 작업자가 수행한다.
- [x] 정보 창의 링크·진단·문서 표시는 테스트 대역으로 검증한다.

## 3. 이력 관리
- [x] 실제 임시 저장소를 이용한 복제·다중 삭제·선택 전환·자동 저장 경합 테스트를 추가한다.
- [x] MainWindow.History.cs와 썸네일 모델을 구현한다. 기존 메인 코드의 제거/연결은 주 작업자가 수행한다.
- [x] 다중 선택 메뉴와 더 보기/자동 추가 로딩·너비/접기 설정을 연결한다.

## 4. 편집과 메인 UI 통합
- [x] 선택 개체/새 개체 속성, 번호 순서, 크기 변경 및 Undo/Redo 회귀 테스트를 추가한다.
- [x] 도구 그룹·문맥 속성·색상/선/번호/모자이크/크기 UI와 각 서비스를 연결한다.
- [x] 마우스 휠·더블 클릭 편집·PNG 이름/폴더 기억을 구현하고 헤드리스 동작을 검증한다.

## 5. 전체 검증과 결과
- [x] Desktop/Core 전체 헤드리스 테스트와 빌드 스크립트 테스트를 실행한다.
- [x] 전체 Release 빌드와 두 CPU 맥 교차 게시·패키지 정적 검증을 수행한다.
- [x] 실행 중 EXE를 확인한 후 Portable Windows EXE를 갱신하고 LFS를 검증한다.
- [x] 코드 검토 지적을 수정하고 docs/macos.md를 최종 구현에 맞춘다.
- [x] 한국어 커밋으로 기록하고 실제 macOS에서 검증하지 못한 부분을 보고한다.

## 검증 결과

- Desktop 헤드리스 120개, Core 45개, 비표시 Windows 정보 창 5개 통과.
- Python 빌드 검증 30개 중 29개 통과, Unix 심볼릭 링크 1개는 Windows에서 제외.
- 일반 Release 빌드 및 Portable EXE 게시 성공. EXE는 Git LFS로 기록한다.
- Apple Silicon·Intel 자체 포함 ZIP 생성 및 CPU/런타임/리소스 정적 검증 통과.
- 코드 검토의 모자이크 선택, 투명 색상, 이동한 앱의 자동 실행 해제 지적을 수정하고 회귀 테스트를 통과했다.
- 새 기능의 실제 macOS 실행·다중 모니터·로그인 실행 검증과 새 DMG 생성은 GitHub 푸시 승인 후 기존 Actions로 진행한다.
- 기존 Windows packages.lock.json 변경은 보존하고 이번 커밋에서 제외한다.
