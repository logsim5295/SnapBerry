# macOS UI Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this approved design inline. Track progress in artifacts/macos-ui-progress.md.

**Goal:** Preserve Desktop features while replacing the ribbon with compact macOS-oriented command bars, sidebar and canvas.
**Architecture:** Keep existing named commands and editor/OS boundaries; reorganize Avalonia views and theme resources only. Use vector icons independent of installed symbol fonts.
**Tech Stack:** .NET 10, Avalonia 12.1.4, Skia, xUnit, Avalonia.Headless.
**Spec:** docs/superpowers/specs/2026-10-23-macos-ui-design.md (approved by user).

## Global Constraints

- Do not modify Windows WPF product source or common editor models. Preserve pre-existing App/packages.lock.json changes.
- Do not launch an app, capture the desktop, activate windows, or run native UI tests.
- Preserve all capture, annotation, history, clipboard, settings and legal functions.
- Verify relevant tests, normal Release build and local Portable publish. No push or installer distribution.

## Review Focus

- At 820 × 560, every command remains reachable without consuming the canvas with wrapped button rows.
- Busy and modal states disable all command surfaces, including flyouts and the empty-state capture button.
- Changing tool and theme preserves selection highlighting, keyboard input, history width and saved preferences.
- Dialog details/legal expansion remains readable and scrollable on smaller displays.
- Names and tooltips remain available for icon actions and light/dark contrast stays legible.
