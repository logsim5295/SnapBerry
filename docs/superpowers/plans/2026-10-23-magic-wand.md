# Magic Wand Implementation Plan

**Goal:** 자동 AI 누끼를 Snagit 방식의 색상 선택·삭제 마술봉으로 교체한다.
**Spec:** ../specs/2026-10-23-magic-wand-design.md
**Architecture:** 공통 Skia 색상 선택 세션 + 플랫폼별 선택 도구/오버레이/속성 UI. 기존 비파괴 PNG 자원과 실행 취소를 재사용한다.

- [x] 공통 색상 선택·연결/전체 모드·투명·자르기·지우기 테스트를 추가하고 실패를 확인한 뒤 구현한다.
- [x] AI 모델/패키지/자동 버튼을 제거하고 양쪽 편집기/도구/속성/선택 오버레이/체크무늬/삭제/Esc를 연결한다.
- [x] 문서 전환과 undo 시 선택 폐기, tolerance 재선택, 저장/재열기 테스트를 수행한다.
- [x] 관련 헤드리스 테스트·Release·Portable·macOS arm64/x64 게시/패키지 검증과 독립 검토를 완료한다.

사용자가 앞선 결과를 바로잡고 Magic Wand 동작을 명시했으므로 해당 기준으로 수정하며 추가 승인 단계 없이 진행한다. 기존 `BackgroundAssetHash` 저장/실행 취소 계약은 호환성을 위해 유지한다.

## 검증 기록
- Core 54개, Desktop 154개, Windows 관련 69개 통과. 마지막 마술봉 아이콘 변경 후 아이콘 검사 추가 통과.
- Python 빌드/패키지 테스트 48개 중 47개 통과, 기존 플랫폼 조건 1개 건너뜀.
- 정상 Release 경고 0/오류 0, Portable 게시와 난독화/JSON/번들 검증 통과. Windows EXE에 마술봉 라이브러리가 포함되고 AI 모델·실행 엔진이 없음을 검사했다.
- macOS arm64/x64 교차 게시·패키지 CPU/권한/자체 포함 런타임 검사 통과. 두 패키지에 MagicWandSelection이 있고 ONNX/U2Net 파일이 없음을 검사했다.
- 독립 검토의 두 지적(키보드 지우기 실패 처리, 교체 후 참조 기준의 용량 계산)을 수정했다. 2500×2500 난수 PNG가 자원 한도를 넘을 때 키보드 삭제에서 선택·문서를 유지하고 오류를 안내하는 회귀 테스트가 실패하는 것을 본 뒤 통과시켰다.
- EXE 186,332,578 bytes. 앞선 AI 버전 206,108,272 bytes에서 약 19.8MB 감소했으며 최초 기준 186,303,859 bytes 대비 약 28.7KB 증가했다.
- 앱 실행, 실제 OS 창 표시·화면 캡처·포커스 변경 테스트는 하지 않았다. 실제 macOS 실행·성능·상호작용 검증은 아직 수행하지 않았다.
- 구현 검증 이후 사용자가 커밋과 푸시를 명시적으로 요청했다. 현재 작업 브랜치에 소스·테스트·문서를 커밋하고 푸시하며, 버전 태그나 공개 릴리스는 생성하지 않는다.
