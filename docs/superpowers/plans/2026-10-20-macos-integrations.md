# macOS 클립보드·스티커·전역 단축키 확장

사용자가 요청한 기존 맥 앱 기능 확장이다. Windows 앱과 버전 1.0.1, `.qcapture` 형식을 유지한다. 구현은 현재 세션에서 계속한다.

## 동작과 구조

- 클립보드: Command+C/V, 복사·붙여넣기 버튼. 텍스트 입력 중에는 텍스트 동작을 유지한다. 이력 선택의 복사는 합성 이미지이며, 편집기에서 선택한 이미지 개체는 원본 PNG와 출력 표시 크기를 함께 복사한다. 다른 앱용 표준 비트맵과 SnapBerry용 표시 크기를 함께 제공한다. 열려 있는 문서에는 중앙에 추가하고 빈 편집기는 새 이미지로 연다. 외부 클립보드는 인터페이스로 분리해 테스트에서는 메모리 구현만 사용한다.
- 스티커: Windows 목록 정의를 순수 C# 파일로 분리해 소스 링크한다. 기존 ID·순서·이름·카테고리와 Windows PNG 생성은 유지한다. 맥 PNG는 Skia로 생성하며 한국어 카테고리·검색·비모달 선택창을 제공한다. 생성한 PNG를 문서에 넣어 이동·크기 조절·복제·삭제·Undo/Redo·저장 재열기를 지원한다. 키보드 스티커 라벨도 변경할 수 있다.
- 전역 단축키: Control+Shift+1/2/3을 영역·창·전체 화면 기본값으로 한다. 키 조합을 설정하거나 사용을 끌 수 있다. Carbon RegisterEventHotKey/InstallEventHandler를 별도 네이티브 경계로 감싸고 테스트에서는 가짜 백엔드를 사용한다. 중복·등록 충돌 시 오류를 표시하고 이전 등록을 복구한다. 작업 중·설정 중에는 캡처 요청을 무시한다.
- 메뉴 막대: 편집기 표시·캡처·설정·종료 메뉴를 제공한다. 창 닫기는 저장 후 숨김이며 단축키는 유지한다. 명시적 종료는 저장 성공 후 등록·메뉴 아이콘을 해제한다. 저장 실패 시 숨김/종료를 중단한다.
- 테마 변경은 새 단축키 설정을 덮어쓰지 않는다. 스티커·설정창은 현재 테마를 따른다. 캡처 중 스티커 창도 숨긴 뒤 원래 표시 상태로 복원한다.

## 구현 순서와 검증

- [x] 메모리 클립보드 테스트: 복사 원본/크기·다른 문서 붙여넣기·반복 복제·빈 편집기·손상 데이터·Undo/Redo. 실패 확인 후 클립보드 서비스·편집기·UI 연결.
- [x] 스티커 정의 분리·Skia 생성·한국어 검색·선택/라벨 수정·저장 왕복 테스트. 기존 Windows 카탈로그 회귀 테스트 포함.
- [x] 단축키 파싱·중복·등록 실패/롤백·종료 해제 테스트. 네이티브 호출은 실행하지 않고 C ABI 선언·상수와 fake 백엔드를 검사.
- [x] 메모리 Avalonia 창에서 메뉴·설정·단축키 명령 분기·비활성 상태·테마 보존·저장 실패 후 창 상태를 검증. 실제 창·OS 클립보드·전역 등록·캡처는 실행하지 않음.
- [x] 독립 리뷰와 필요한 수정, Desktop/Core/관련 Windows 테스트, 일반 Release와 Portable 게시·번들 검사, 두 CPU용 macOS ZIP 재생성·검증·문서. 한국어 커밋으로 남기고 푸시하지 않음.

검증 결과: Desktop 62개, Windows 비대화형 94개, Core 45개 통과. Release 경고·오류 0개. 리뷰에서 발견한 Carbon의 ByteCount/ItemCount는 nuint로 수정했으며 수정 전 실패하는 회귀 테스트를 추가했다. 화면 검증은 메모리 렌더링만 사용했다. 상세 결과는 `docs/verification.md`에 기록한다.

macOS 실기기의 클립보드 형식·전역 단축키·Carbon 이벤트 전달·메뉴 막대·서명·캡처 권한은 이 Windows 환경에서 검증할 수 없으며 완료로 표현하지 않는다.
