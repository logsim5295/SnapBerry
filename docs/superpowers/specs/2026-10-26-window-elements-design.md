# 창 내부 요소 캡처

사용자가 요청한 창 캡처 확장: 마우스 아래 메시지 박스, 버튼, 패널을 자동 선택하고 표시된 사각형을 클릭해 캡처한다. Windows WPF 앱에 적용한다.

구현 판단: 기존 창 선택만으로는 내부 컨트롤을 찾지 못하며, 네이티브 자식 창만으로는 WPF 등의 요소를 찾지 못한다. 창 핸들 기반 UI Automation 탐색과 네이티브 자식 창 탐색을 함께 사용한다. 화면 전체의 FromPoint는 캡처 오버레이를 가리키므로 사용하지 않는다.

후속 진단에 따라 DWM cloaked 창을 후보에서 제외한다. 원본 HWND의 MSAA hit-test를 먼저 사용하고 UI Automation을 대체 경로로 유지한다. MSAA의 OFFSCREEN만으로 요소를 버리지 않고 실제 숨김 상태, 경계, 소유 HWND를 검사한다. 느린 조회는 결과를 보관하되 캡처 세션과 HWND 및 포인터가 모두 일치할 때만 재사용한다.

기본 선택은 가장 안쪽 요소다. 휠 위/아래로 부모/자식 영역을 선택하며 전체 창도 항상 선택 가능하다. 요소를 제공하지 않는 앱, 권한 제한, 시간 초과에서는 네이티브 자식 창 또는 전체 창을 사용한다. 버튼 안의 텍스트처럼 원자적 컨트롤의 장식은 따로 선택하지 않는다.

UI Automation은 제한된 단일 백그라운드 작업으로 실행한다. 이전 마우스 위치의 결과와 종료 후 결과는 버린다. 화면 좌표는 물리 픽셀이며 부모 및 캡처 화면 밖의 경계는 자른다. 캡처 이미지는 기존 고정 프레임을 사용한다.

창 표시, 앱 활성화, 실제 화면 캡처를 수행하는 테스트는 사용자 승인 없이 실행하지 않는다. 헤드리스 테스트, 일반 Release 빌드, Portable 로컬 게시로 검증한다. 실행 중 EXE를 덮어쓰지 않으며 커밋/푸시는 이번 작업에 포함하지 않는다.
