# 마술봉 색상 선택 도구

사용자가 원한 기능은 Snagit Magic Wand와 같은 색상 선택이다. 앞서 만든 자동 AI 누끼를 이 도구로 교체한다. Windows/macOS 모두 클릭 → 선택 미리보기 → 허용 오차 조절 → 전체 색상 선택(선택 사항) → Delete/선택 지우기 흐름을 제공한다. Esc나 다른 도구 선택으로 선택만 취소한다.

사전학습 모델·ONNX Runtime·런타임 다운로드를 제거한다. Skia 기반 공통 픽셀 처리에서 클릭 색상과의 RGB 채널 차이를 비교한다. 기본값은 클릭 지점에 연결된 영역만 선택하고, 전체 색상을 켜면 현재 자르기 영역의 떨어진 동일 색상도 선택한다. 투명 픽셀은 제외하며 자르기 밖의 픽셀은 선택·삭제하지 않는다.

선택과 허용 오차 조절은 문서나 실행 취소 이력을 변경하지 않는다. 선택 영역에 색상 오버레이를 보여주고, 지우기를 확정할 때만 한 번의 실행 취소 명령으로 새 투명 PNG를 적용한다. 기존 원본·주석·자르기·출력 크기와 이력 저장 방식은 보존한다. 투명 영역은 편집 화면에서 체크무늬로 표시하며 내보내기에 선택 표시나 체크무늬를 포함하지 않는다.

픽셀 처리는 공통 Imaging 프로젝트에 두고 양쪽 편집기가 선택 세션을 관리한다. 문서 전환/실행 취소/다시 실행 시 세션을 폐기해 오래된 선택을 적용하지 않는다. 색상 선택은 원본 이미지 레이어를 대상으로 하며 도형·텍스트·삽입 이미지 개체를 수정하지 않는다.

앱 실행·실제 OS 창 표시·화면 캡처 없이 관련 테스트, 일반 Release, Windows Portable 게시, macOS 두 CPU 교차 게시와 패키지 검증을 수행한다. 푸시하지 않는다.
