# macOS 기능 동등성 설계

사용자가 확인한 Windows/macOS 차이를 기준으로 맥의 미구현 기능을 보완한다. 기존 Avalonia 앱, 공통 문서 좌표, `.qcapture` 형식, 실행 취소·자동 저장 구조를 유지한다. Windows 패키지 잠금 파일의 기존 변경은 보존한다.

- 편집: 이미지 해상도 변경, 시각적 색상 선택, 선 모양, 4~64 모자이크 블록 크기, 숫자/영문 소문자/대문자 순번·다음 값·글자색, 텍스트 더블 클릭 편집, 휠 확대·축소를 제공한다. 설정은 선택 개체와 새 개체에 정확히 적용하고 실행 취소와 저장에 포함한다.
- UI: 홈/보기의 도구 그룹과 문맥별 속성을 제공한다. 빈 편집기의 안내, 다크 테마, 작업 중 명령 잠금을 유지한다.
- 이력: 썸네일, 다중 선택·일괄 삭제, 이력 자체 복제·이름 변경, 메뉴/키보드 명령, 첫 선택·삭제 후 인접 항목 선택, 자동 추가 로딩, 목록 접기·너비 보존을 제공한다. 삭제는 확인 후 수행하고 자동 저장과 경합해 삭제된 파일이 복구되지 않아야 한다.
- 저장: 이력 이름을 PNG 기본 이름에 반영하고 최근 저장 위치를 보존한다. 이미지/주석의 크기는 화면 확대와 구분한다.
- 운영체제: 전체 화면 캡처를 연결된 모든 디스플레이의 배치에 맞춰 합성한다. macOS 로그인 자동 실행은 사용자별 LaunchAgent와 앱 내부 설정으로 관리한다. 실행 파일 경로는 안전하게 plist로 직렬화하고 외부 명령에 문자열 쉘 결합을 사용하지 않는다.
- 설정/정보: 실제 키 조합 입력·기본값 복원, GitHub/버전/진단/저장 폴더/이용약관·데이터 처리·외부 구성 요소 안내를 제공한다. 외부 실행과 클립보드는 명시적인 사용자 명령에서만 수행한다.

검증은 헤드리스 UI·문서·실제 임시 저장소·가짜 OS 경계 테스트로 수행한다. 일반 테스트에서 실제 OS 캡처·로그인 설정·브라우저·GUI는 실행하지 않는다. 로컬 Mac이 없으므로 네이티브 동작 검증 범위와 실행하지 못한 항목을 구분한다. Apple Developer ID/공증은 이번 범위가 아니다.
